# 🚖 Uber Ride Analytics Dashboard | Power BI Project

## 📌 Project Overview
This project presents an interactive Uber Ride Analytics Dashboard developed using Microsoft Power BI. The dashboard analyzes ride-booking data and provides meaningful insights into booking performance, revenue, vehicle performance, rider behavior, and location analysis.

## 🎯 Project Objectives
- Analyze overall ride-booking performance.
- Track completed and lost bookings.
- Understand revenue trends and payment methods.
- Compare vehicle-wise performance.
- Analyze first-time and returning riders.
- Identify pickup location and trip distance patterns.
